# AirFryer Recipes Website

🍳 This repository contains the AirFryer Recipes website, built using HTML and CSS. The site features a clean, responsive web design, showcasing a variety of air fryer recipes. It utilizes native CSS for styling, ensuring a user-friendly experience across different devices and screen sizes.

## ✨ Features
- 📱 **Responsive Design**: Automatically adjusts the layout for a seamless experience on desktops, tablets, and mobile devices.
- 🍲 **Recipe Showcase**: Displays a range of air fryer recipes, categorized for easy access.
- 🚦 **User-Friendly Navigation**: Simple and intuitive navigation bar to explore different recipes.
- 🎨 **Modern Styling**: Clean design using native CSS for improved user experience.

## 💻 Technologies Used
- 🌐 **HTML5**: For structuring content and elements of the website.
- 🎨 **CSS3**: For styling the website with modern layout and design techniques.

## 🚀 Installation
To view and test the website locally:

1. **Clone the repository**:
```bash
git clone https://github.com/nadeesamaraweera/Food-Recipe.git
```

2. **Open `index.html` in your browser**:
```bash
open index.html
```

## 📖 Usage
- 🍽️ **Recipe Listings**: Offers a variety of air fryer recipes to explore.
- 📂 **Categories**: Recipes are organized for easy browsing and selection.
- 📱 **Responsive Design**: Optimized to work on desktops, tablets, and mobile devices.
